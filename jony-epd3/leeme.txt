                        1. DESCRIPCIÓN DEL EJERCICIO
================================================================================

Implementación de un programa modular en JavaScript que calcula el coste de
envío de un paquete a partir de los datos solicitados secuencialmente al
usuario mediante la función prompt().

Entrada de datos:
  1. Peso del paquete en kilogramos (pesoReal).
  2. Dimensiones del paquete en centímetros: largo, ancho y alto.
  3. Tipo de destino: LOCAL, NACIONAL o INTERNACIONAL (insensible a mayúsculas).

Validaciones exigidas:
  • Peso real: valor numérico mayor que 0 y menor o igual a 30 kg (acepta
    como máximo un decimal).
  • Cada una de las dimensiones (largo, ancho, alto): número entero mayor
    que 0 y menor o igual a 120 cm.
  • Tipo de destino: debe coincidir exactamente con una de las tres opciones
    válidas (LOCAL, NACIONAL o INTERNACIONAL), permitiendo cualquier combinación
    de mayúsculas y minúsculas.
  • Mensaje unificado de error: si cualquiera de los datos es incorrecto o
    no numérico, el programa devuelve y presenta exactamente el mensaje:
    ERROR: <<TIPO DE ERROR COMETIDO>>

Reglas de cálculo implementadas:
  • Peso volumétrico:
      pesoVolumetrico = (largo * ancho * alto) / 5000
  • Peso facturable:
      pesoFacturable = Math.ceil(Math.max(pesoReal, pesoVolumetrico))
  • Tarifas por kilogramo facturable:
      - LOCAL: 2.50 €/kg
      - NACIONAL: 4.00 €/kg
      - INTERNACIONAL: 8.50 €/kg
  • Suplemento fijo internacional:
      - Envíos a destino INTERNACIONAL suman un suplemento fijo de 12.00 €.
      - Destinos LOCAL y NACIONAL: 0.00 €.
  • Recargo por peso elevado:
      - Si pesoFacturable > 20 kg, se aplica un 15% sobre el subtotal del envío.
  • Función obligatoria 'calcular(pesoReal, largo, ancho, alto, destino)':
      Retorna un objeto con el desglose del envío:
      {
        pesoReal: ...,
        pesoVolumetrico: ...,
        pesoFacturable: ...,
        suplemento: ...,
        recargo: ...,
        precioTotal: ...
      }
  • Presentación en pantalla:
      Formateo estricto con dos decimales mediante .toFixed(2), respetando
      la salida de los ejemplos oficiales del guión.
